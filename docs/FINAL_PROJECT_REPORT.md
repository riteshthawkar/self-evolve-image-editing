# Final Project Report: Self-Evolving Image Editing

This file is the canonical project reference. When describing the project, experiment setup, data pipeline, reward system, or training/evaluation procedure, use this document first.

## 1. Project Framing

The project studies **self-evolving post-training for instruction-guided image editing**.

The base editor is the released `Qwen/Qwen-Image-Edit-2509` checkpoint. We do **not** claim to reproduce Qwen's original large-scale training. Instead, we use Qwen-Image-Edit-2509 as the base policy and add a self-evolving loop on top:

```text
source image
-> proposer creates edit instruction
-> Qwen editor samples K candidate edits
-> internal reward/evaluator selects preservation-safe edits
-> accepted edit pairs become training data
-> LoRA/full post-training updates the editor
```

The research claim is:

```text
Generic self-evolution is insufficient for image editing because image editing has a coupled objective:
the model must satisfy the edit instruction while preserving non-target content.
We therefore use an internal contrastive edit-preservation reward that accepts only edits that are both
instruction-specific and preservation-safe.
```

## 4. Data Filtering

Self-evolution should not use arbitrary images. A useful source image must be editable, visually clear, and contain non-target structure that can test preservation.

The source-image filter performs:

```text
raw image pool
-> technical quality checks
-> open-VLM editability judgment
-> diversity / near-duplicate filtering
-> selected source manifest
```

Open-VLM backend:

- default: `Qwen/Qwen3-VL-8B-Instruct`
- stronger H200 setting: `Qwen/Qwen3-VL-30B-A3B-Instruct`

Filtering signals:

- resolution and aspect ratio
- exposure and contrast
- sharpness and entropy
- clutter / watermark / dense text penalties
- editability
- preservation potential
- plausible edit families
- source diversity using average-hash distance

Selected manifest line:

```json
{
  "key": "image_key",
  "image": "path/to/image.png",
  "caption": "short VLM caption",
  "metadata": {
    "source_selection_score": 0.73,
    "edit_families": ["color", "tone", "local"],
    "primary_family": "color"
  }
}
```

The self-evolve proposer can use `metadata.primary_family` and `metadata.edit_families` to prefer edits that are plausible for each image.

The filtering stage is resumable. It streams `scores.jsonl`; rerunning with the same output directory reuses already scored images and rebuilds `manifest.jsonl` from the accumulated scores.

## 5. Final Reward Model: Internal CEPR

The main method uses **Internal Contrastive Edit-Preservation Reward (Internal CEPR)**.

It is internal-only. It does not use GPT-4V, external CLIP, external VLM judges, detectors, OCR, or segmentation models.

For source image `x`, instruction `c`, and candidate edit `y_i`:

```text
R(y_i | x, c) = sqrt(E_i * P_i)
```

with hard gates:

```text
E_i >= tau_E
P_i >= tau_P
Q_i >= tau_Q
R_i >= tau_R
```

If any gate fails, the candidate reward is set to zero and it is not used for editor training.

### 5.1 Edit Specificity

`E_i` measures whether the candidate edit is specifically aligned with the true instruction rather than a nearby wrong instruction.

```text
E_i =
sqrt(
  sigmoid((Delta_true_i - max_j Delta_wrong_ij) / T_E)
  *
  sigmoid((Delta_true_i - gamma) / T_abs)
)
```

where:

```text
Delta_true_i = sim_Q(y_i, c) - sim_Q(x, c)
Delta_wrong_ij = sim_Q(y_i, c_wrong_j) - sim_Q(x, c_wrong_j)
```

`sim_Q` is computed from Qwen's own internal image-text representations.

Purpose:

- prevents no-op outputs
- prevents random edits that look plausible but do not match the instruction
- prevents reward hacking through unrelated visual changes

### 5.2 Preservation

`P_i` measures whether non-target content is preserved:

```text
P_i = sqrt(P_sem_i * P_lat_i)
```

`P_sem_i` is semantic preservation from Qwen's internal understanding features using a blank/preservation prompt.

`P_lat_i` is Qwen VAE latent preservation outside the inferred edit region:

```text
M_i = 1[latent_delta(x, y_i) > mean + alpha * std]
P_lat_i = exp(- outside_latent_delta / T_P)
```

Purpose:

- penalizes destructive full-image regeneration
- encourages edits that affect the target content while preserving surroundings
- handles the central image-editing failure mode: over-editing

### 5.3 Validity Gate

`Q_i` is not an additive reward. It is only a rejection gate:

```text
Q_i = sqrt(region_plausibility_i * latent_drift_score_i)
```

Purpose:

- rejects unstable or destructive candidates
- prevents visual quality from compensating for wrong edits
- keeps training data conservative

### 5.4 Candidate Selection

For each source image and instruction, sample `K` candidates:

```text
y* = argmax_i R(y_i | x, c)
```

Only the top feasible candidate is accepted by default.

## 11. Paper Story

The clean paper story is:

```text
Self-evolution for image editing should not simply reward outputs that look good.
Image editing requires a constrained objective: change the requested content and preserve the rest.
Our Internal CEPR reward uses the editor's own representations to select self-generated edits that are
instruction-specific and preservation-safe, enabling post-training without external reward models.
```

What we should not claim:

```text
We reproduce Qwen's original training.
We use Qwen's private data.
We have a universal reward for all edit types.
We improve every benchmark category before experiments prove it.
```

What we can claim if experiments support it:

```text
Internal self-evolution improves selected image-editing categories under a fixed Qwen-Image-Edit-2509 base.
The gains come from better pseudo-edit selection, not from external VLM supervision.
The reward is especially suited to preservation-sensitive image editing.
```
